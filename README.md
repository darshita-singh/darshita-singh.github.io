# Darshita Singh — Portfolio

A static portfolio for GitHub Pages.

## Customize before publishing

Search for these placeholders and replace them:

- `YOUR-GITHUB-USERNAME`
- `YOUR-LINKEDIN-USERNAME`
- `YOUR-EMAIL@example.com`

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload everything in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io`

## Project repositories

The project cards currently point to placeholder repositories. Create/update the repositories and replace the URLs in `index.html`.
